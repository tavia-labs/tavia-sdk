# Tavia SDKs

Client libraries for the Tavia API: realtime voice sessions, speech-to-text and text-to-speech.

| Language | Package | Guide |
|---|---|---|
| TypeScript / JavaScript (browsers and Node) | `@tavia/sdk` | [js/README.md](js/README.md) |
| Python | `tavia` | [python/README.md](python/README.md) |

Both SDKs talk to `https://api.tavialabs.com/v1` and share the same concepts: a client holding your credentials,
realtime sessions with typed events, tools your agent can call, and typed errors.

Documentation: https://app.tavialabs.com/docs
