# Security

If you believe you have found a security issue in these SDKs or the Tavia API, please report it privately to
hello@tavialabs.com. Do not open a public issue.

Please include what you found, how to reproduce it and the SDK version. We will acknowledge your report, keep you
informed while we fix it, and credit you if you wish.

Never include API keys or other credentials in a report. If a key has been exposed, revoke it in the console first.
